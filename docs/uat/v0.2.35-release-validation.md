# AI Marketplace v0.2.35

- Open Guardrail Evaluation in the Tech workbench, select a Guardrail version, choose a configuration from Evaluate, and start a run. Reopen the same Guardrail version to see its recorded runs and reports.
- Evaluate runs its selected configuration against that configuration's endpoint. Marketplace records the association for display. Provider acceptance continues to govern sign-off.
- Swagger documents configuration discovery, selection, submission, progress, report retrieval, and the existing mock fallback when Evaluate is unconfigured.
