# v0.2.26 发布验证

本版完善 V2 Measure 页面：View Scan 的 Profile Info 增加 “Go To Set Bypass Mode [Kill Switch]” 入口，跳转到现有 Profile Dashboard。当前 Scan 的 Profile 关联仍是 placeholder，由用户选择 Profile 后进入既有 Bypass 操作；跳转本身不改变运行模式。

Agent 和 Guardrail 两条下钻路径的 Policy 扫描页标题统一为 “Agent Policy Scans”。移除 Measure 顶部单独的 Scan Overview 标签栏，保留概览页面和返回导航。

Tech Feedback Review 页面直接展示 Feedback Closure：必填关闭说明、可选 JIRA、Go Back 和 Close feedback。提交后展示 feedback 本身的 Closed 状态预览；返回反馈列表保留筛选。指标和记录继续使用 placeholder，关闭说明仅保留在页面内存，不创建真实或模拟反馈记录，不发起真实关闭请求。

验证覆盖 Scan 跳转及不触发 Bypass、扫描标题、关闭说明校验、Closed 状态预览和返回筛选。类型检查、生产构建及浏览器交互检查已通过；全量回归：200 个测试文件通过、3 个跳过；1196 项测试通过、9 项跳过。镜像验证见 Release 附件及发布流水线。

升级使用 0.2.26 镜像与 Chart，无新增必填配置或数据迁移。沿用现有 V3 连接和 Secret 配置。
