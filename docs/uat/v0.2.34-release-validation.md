# AI Marketplace v0.2.34

- With no Evaluate URL configured, V3 can run an independent evaluation and reopen its sample report. The UI labels the result **Mock evaluation**. The API identifies simulated setup, runs and reports with `source: "mock"`.
- Configuring a working Evaluate URL switches the panel to live runs. Errors from a configured service are reported. Provider acceptance still controls sign-off.
- Shared V3 defaults to skipping certificate verification for its configured NeMo, F5 and Evaluate APIs. Each connection offers **Verify certificate**. Database TLS uses its own settings.
- The release includes the Linux amd64 image, versioned Helm chart, offline bundle and Swagger contract. Use the existing workspace and connection storage when upgrading.
