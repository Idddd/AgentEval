# v0.2.27 发布验证

本版完善真实 NeMo/F5 集成和部署诊断，并包含已验收的 V2 导航调整。

## 改动

- NeMo 已有 Policy/Guardrail 的真实数据导入、原生资源只读展示及精确版本绑定；刷新不重复创建。V3 Guardrail 经 Tech 选择 NeMo 并保存配置后同步 Policy 草稿，Profile 保存后同步 NeMo Guardrail 草稿。
- 可选 F5 URL、Token、CA 连接测试与契约验证；创建、评测和发布保持真实远端 ID/版本。F5 配置错误、权限拒绝、超时和不兼容响应有明确错误与追踪编号，不阻断 NeMo。
- F5 远程请求不持有共享数据库锁；以来源实例租约协调共享 Scanner 更新，防止并发覆盖与过期结果覆盖。结构化日志和操作审计可关联追踪，不记录 Token 或扫描正文。
- Swagger 补齐页面 API 对照、请求/响应 schema 与真实响应验证，明确 placeholder 和未接入能力，不把 Mock 数据作为真实接口结果。
- 已配置工作区隐藏 Connection settings 按钮，手动通过 `/v3/guardrails#connection` 进入；配置缺失时自动进入。V2 Measure Kill Switch 直接打开 Customer Banking Assistant 侧栏，显示现有 Bypass 控件。

## 验证

- Marketplace：202 个测试文件通过、3 个跳过；1232 项测试通过、9 项跳过。首次默认高并发运行一个既有 UI 测试达到 5 秒超时；降低并发到 4 后完整复跑通过。
- Runner/MCP：26 项测试通过、1 项需要外部集成环境的测试跳过。
- 全部工作区类型检查、Marketplace 生产构建和独立代码审查通过。本地缺失的 Runner/MCP 依赖已按锁文件补齐，未更改版本。
- 浏览器创建 Guardrail 和 Profile 后，直接读取真实 NeMo API 核对名称、检测规则、远端 ID、草稿版本和精确 Policy 绑定；两项同步均成功，刷新无重复。测试资源保留为未发布草稿，测试数据与凭据不包含在发布包内。
- 真实 NeMo/MariaDB 下，F5 无效配置或连接失败时，已有资源仍正常读取及导入。
- HTTP/Swagger 审核：15 个响应、29 个 schema、12 个操作和14项页面映射通过。
- 发布流水线继续检查 Linux amd64 镜像启动、只读文件系统、源码/Chart 完整性、Helm 渲染和16项依赖故障隔离。F5 配置错误应被记录，但不再拦截数据库/NeMo检查。

## 升级与边界

使用 `ghcr.io/idddd/tali-ui-demo:0.2.27` 和 `oci://ghcr.io/idddd/charts/tali-ui-demo` 版本 `0.2.27`。无新增必填配置；保留现有 NeMo URL、workspaceId、数据库、Secret 和持久化连接目录。不要清除已有共享配置或数据库。

没有目标 F5 实例，本次 F5 验证为官方文档契约与故障测试；部署时仍需验证实际版本、权限、网络及 CA。F5 存量资源导入、流量接入和实时 Measure 数据没有在本版新增。V2 Mock 继续独立运行。
