# v0.2.28 发布验证

本版发布独立资源 API、V3 路由修复、NeMo Policy JSON 编辑和 V2/V3 创建侧栏调整。

## 改动

- 新增 `/api/nmgr/v1` 下 36 个资源操作，覆盖 Guardrail/Profile、评估、审批、部署、任务恢复、审计、Dashboard 与 NeMo 导入；保留既有 workspace/commands 接口兼容。
- Swagger 共 48 个操作、44 个 schema、14 项页面映射。结构化日志带 request/operation ID、耗时和安全资源标识，不记录 Token 或请求正文。
- V3 导航、详情和浏览器返回保持在 V3；修复历史状态和 Skip to content 路由覆盖。
- NeMo Custom Policy 明确使用可执行 JSON，前后端共享基础结构检查。空编辑器显示灰色 sample，Tab 填入并展开滚动区域；F5 继续使用原有配置格式。
- V2/V3 的列表及 Dashboard 新建 Guardrail 均打开右侧栏，保留原页和未保存确认；V3 保存失败保留输入并显示错误。
- 更新 Guardrail Dashboard、Configurate Guardrails、Redirected 文案，修正实施方为 Tech，移除重复 Versions 区块及 V2 失败模拟 checkbox。

## 本地验证

- Marketplace 全量：207 个测试文件通过，3 个跳过；1280 项测试通过，9 项跳过。
- Runner/MCP：26 项测试通过，1 项外部集成测试跳过。
- 所有工作区 TypeScript 检查、Marketplace 生产构建通过。
- 真实 HTTP/Swagger 核对：33 个响应、44 个 schema、48 个操作、14 项页面映射通过，查询 43 个已有资源；没有新增或发布业务资源。
- 浏览器确认 V2/V3 列表与 Dashboard 的创建侧栏；自动化覆盖取消、未保存确认、请求失败保留输入、重试成功和 V3 详情路由。
- NeMo 自定义 JSON 的真实同步证据见 [验收记录](2026-11-05-custom-policy-validation.md)；独立 API 与兼容性证据见 [API 验证](2026-11-05-resource-api-validation.md)。

## 发布与升级

镜像 `ghcr.io/idddd/tali-ui-demo:0.2.28`，Chart `oci://ghcr.io/idddd/charts/tali-ui-demo`，版本 `0.2.28`。

发布流水线验证 Linux amd64 镜像启动、只读文件系统、嵌入源码和 Chart、Helm 渲染及 16 项故障隔离，再发布 OCI Chart。实际流水线结果、镜像摘要和离线包校验文件随 GitHub Release 提供。

从 v0.2.27 升级无新增必填配置或数据库迁移；保留 NeMo URL、workspaceId、数据库、Secret 和持久化连接目录。旧 UI 继续使用兼容接口，外部 UI 可使用 [独立资源 API](../resource-api.md)。

没有真实 F5 实例，本版覆盖契约与故障隔离回归，目标实例仍需部署后验证。实时 Measure、反馈闭环、流量追踪和 V3 Bypass 等未接入能力保持明确标识，不添加虚构数据。
