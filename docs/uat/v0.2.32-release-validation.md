# AI Marketplace v0.2.32

- The published Helm chart and offline bundle use the versioned Linux amd64
  image `ghcr.io/idddd/tali-ui-demo:0.2.32`.
- The UAT example inherits the chart's image repository. Deployments using
  a mirror set the repository and pull secret in their own values.
- The release workflow verifies the chart's default and UAT rendering and pulls
  the version tag before packaging the offline image.
- `GET /api/nmgr/v1/me` returns the caller's Marketplace role and control
  unit using the existing identity verification and account mapping.
- V3 retains the existing page text from v0.2.31.
  No database migration is required. Preserve workspace and connection storage.
