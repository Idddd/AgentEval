# AI Marketplace v0.2.31

## Changes

- Evaluate connection tests distinguish missing configuration, an unapproved URL,
  and upstream HTTP or network failures. The connection activity log records the
  failing stage, status, and request reference.
- V3 Demo supports encrypted JSON export and import of manually saved connection
  settings. Restore requires the original deployment connection key and validates
  the settings before replacing the current configuration.
- V3 Demo supports browser-reported same-origin requests when ingress rewrites the
  request host. Strict V3 supports exact browser origin allowlists in advanced
  connection settings for authenticated requests to the versioned resource API.
- Deployment templates leave actual NeMo, F5, and Evaluate addresses unset.
  Configure the deployment-specific values after upgrading.

## Deployment

- Linux amd64 image `ghcr.io/idddd/tali-ui-demo:0.2.31`.
- Helm chart `oci://ghcr.io/idddd/charts/tali-ui-demo`, version `0.2.31`.
- Preserve the workspace ID and connection storage on upgrade. No database
  migration is required. Configure Evaluate's URL or approved fallback addresses
  in the deployment values. Keep credentials in deployment Secrets.
- The offline bundle includes the verified image, chart, configuration templates,
  deployment notes, and checksums.
