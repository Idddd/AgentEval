# AI Marketplace v0.2.36

- Create a Guardrail or Profile through the V3 resource API with a fresh requestId and omit draft.id. Read the assigned ID from item.id. Retrying the same requestId and body returns the same resource.
- Clients can continue supplying a valid ID. An invalid draft.id returns HTTP 422 with the accepted format.
- The create schemas and examples in Swagger and the downloadable openapi.json document optional IDs.
