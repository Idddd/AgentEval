# v0.2.23 发布验证

本版沿用当前 NMGR 界面、NeMo/F5 流程与 PostgreSQL/MariaDB 存储，新增默认 V3 三项连接配置、同页高级 fallback、掩码输入、共享加密保存及可选 PVC。V2 Mock 与真实集成继续独立。

发布前本地验证：1159 项 control 测试通过、9 项跳过；TypeScript 检查通过；8 组 Helm 配置渲染和 16 种镜像故障场景通过。干净容器只填写 NeMo URL、业务 Token、完整 DB URL 即可实际连通本地 NeMo/MariaDB，无 SSO、账号映射、Origin 或工作区额外参数。默认 `/v3/guardrails` 已通过浏览器验证：错误部署配置可直接在同页高级设置中修复，保存后进入工作区，没有额外隐藏配置页面。

保存验证覆盖：加密文件与重建后读取、跨客户端共享、接口和日志不回显凭据、失败保存保留旧配置、更换 NeMo/F5 地址须新 Token、旧页面连接版本失效、显式严格身份模式不使用演示保存值。可信 CA 通过真实 localhost HTTPS 自签证书验证，内置信任仍拒绝该证书。独立审查发现未消费错误响应拖延诊断，已改为每次操作独有的 dispatcher.destroy；回归通过，独立复测错误响应在 34 ms 内返回。

发布工作流另外对正式镜像执行：mock/live/随机 OCP UID 启动、浏览器及内存演示行为、嵌入源码/Chart 完整性、Helm lint 和模板、16 种真实配置故障。具体发布镜像标识和逐项结果以随包 `isolation-test-results.json`、`manifest.json` 与 Actions run 为准。

发布审查另发现 Docker 全新 named volume 的目录属主问题；修复前非 root 写入返回 EACCES，修复后新卷写入与重建容器读取均通过。两份镜像 Dockerfile 均在构建时准备 node 所有的目录，工作流增加全新卷读写回归。

默认 V3 演示允许访问者切换角色并配置共享连接。空目录默认使用 emptyDir，可跨浏览器及同 Pod 容器重启保留；Pod 替换后保留需要既有 PVC。镜像、源码和离线包不包含本地测试凭据、已保存连接或数据库。公开 localhost TLS 证书和测试密钥只用于回归。

验证边界：真实本地 NeMo 使用已验收 Controller/Runner 提交；F5 使用契约测试，未连接目标内网 F5。目标 OCP 网络、SCC/卷权限、数据库账号权限、CA、NeMo API 版本、模型、Runner、真实评测与发布仍需内网验收。UI 健康仅表示 UI 可服务。
