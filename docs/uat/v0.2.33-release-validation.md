# AI Marketplace v0.2.33

- In shared V3, open Connections → Independent Evaluate, test and save an HTTPS service hostname on port 443. Empty deployment settings support direct setup. Explicit destinations and deployment token pinning still apply.
- Download [openapi.json](https://github.com/Idddd/AgentEval/releases/download/v0.2.33/openapi.json) and [the frontend integration guide](https://github.com/Idddd/AgentEval/releases/download/v0.2.33/resource-api.md). The running server serves the same contract at `/api/openapi.json` and interactive Swagger at `/api/docs`.
- New Guardrails and Profiles accept a request ID and draft without a workspace revision. Writes to an existing record check changes to that record. Identical retries remain idempotent.
- Resource version lists, Guardrail detail's `usedByProfiles`, evaluation version filters and field-level UI mappings support independent frontends.
- Preserve existing workspace and connection storage. Deployment-specific URLs remain operator inputs. The release contains the Linux amd64 image, Helm chart and offline bundle.
