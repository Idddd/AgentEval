# v0.2.29 release validation

## Changes

- Measure uses two aligned ranking cards with Name / Hits / Action columns,
  prominent hit counts and consistent summary-card borders and selected states.
- V2 User and Approver Measure pages generate local mock traffic every five
  seconds while visible. Hidden pages pause generation; approved kill requests
  stay excluded from traffic generation and the Agent ranking.
- Agent kill requests require confirmation, remain pending until the Control
  Unit Approver approves or rejects, and retain requester/reviewer timestamps.
  The existing V2 runtime simulates the operation; no external Agent is killed.
- Guardrail Actions open searchable linked-Profile navigation with one active
  operation pane. Profile selection survives traffic refreshes and drafts stay
  isolated per Profile. Narrow drawers use a stacked layout.
- Dashboard labels transferred traffic as Modify.
- Includes the latest integration-branch F5 catalog/diagnostic improvements.

## Local verification

- Control/Marketplace: 211 test files passed, 3 skipped; 1318 tests passed,
  9 skipped. Mock/live isolation and the existing integration API tests pass.
- Control TypeScript check and production build passed.
- Browser verification covered 1117px and 1391px desktop layouts, no horizontal
  overflow, live mock hits, user confirmation, Approver review, persistence after
  refresh, Agent removal, and 720px/360px operation-drawer layouts.
- Automated tests cover searching twelve linked Profiles and isolation of mode
  drafts between two Profiles.
