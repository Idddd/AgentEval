# AI Marketplace v0.2.30

## Changes

- V3 Guardrail Evaluation connects to the standalone evaluation API. Marketplace
  shows queued/running state, report preparation, mismatches, and execution
  errors. Refresh resumes the latest run from the backend, without submitting it
  again. Existing provider acceptance remains separate for sign-off.
- Shared V3 Demo keeps role switching and supports independent evaluation for all
  workbench roles in its workspace. Restrict the deployment to a dedicated
  internal UAT environment and test project. Strict V3 still requires an
  authenticated Tech role.
- The Connections page supports Evaluate URL tests, a deployment default, an
  approved manual fallback, and restoration of just the evaluation default.
  Testing and restoring do not launch evaluations or modify other connections.
  Tokens are managed by the deployment and pinned to their service URL.
- Connection tests, saves, restores, and submissions appear in a bounded
  activity log with request references. Credentials and case contents are
  omitted.
- The configured browser-facing origin now works in both V3 modes when a gateway
  rewrites the HTTP host. Requests from other origins remain blocked.

## Validation

- A local Marketplace Demo User triggered a real independent evaluation against
  a local NeMo Runner: 4/4 synthetic cases matched, with no execution errors.
- Tested the deployment URL, a read-only probe of an alternate address, explicit
  save, and restore on the production build without requiring NeMo or database
  connectivity for the Evaluate settings action.
- Origin regression tests cover approved requests through a rewritten ingress
  host, rejected cross-site requests, and independent Evaluate access for Demo
  and strict V3.

## Deployment

- Image: `ghcr.io/idddd/tali-ui-demo:0.2.30` (Linux amd64).
- Chart: `oci://ghcr.io/idddd/charts/tali-ui-demo`, version `0.2.30`.
- No Marketplace database migration is required. Preserve the existing NeMo
  connection and workspace ID. Use the supplied Evaluate Helm values as an
  optional overlay, and configure the actual scan endpoint, endpoint credential,
  and published suite on the Evaluate service.
- The offline bundle includes the image, chart, deployment documentation,
  Evaluate values, and checksums. The public release is a Marketplace release;
  deploy the independent evaluation service separately.
